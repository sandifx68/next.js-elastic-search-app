This is a [Next.js](https://nextjs.org) project I started in order to learn (vectorized) elastic search. Therefore, two birds in one stone: the currently popular Next.js framework and the strong elastic search engine.

## Highlights

- Next.js stack with Prisma + PostgreSQL for the database part.
- (SOON) Elastic search for looking up posts.
- (SOON) Vectorized elastic search for semantic search.
- Unit tested throughout with Jest.
- Integration tests written in Playwright.
- Pipeline running the two types of tests on every push.
